# PRJXP Hub Documentation

Welcome to the PRJXP Hub documentation. Use the tree on the left to browse the chapters.

## What is PRJXP?

PRJXP is a code-aware RAG platform: it chunks your source code, embeds the chunks,
and answers questions about your projects with retrieval-augmented generation.
